# Orea UI

Preview gallery of copy-paste animated React components.

## Commands

```sh
npm run dev      # local server (Next.js 16 App Router)
npm run build    # production build
npm run lint     # ESLint (Next.js built-in config — no local eslintrc)
```

## Skills

Reusable skills live under `skills/`. **Before creating, designing, or adding an
animated component — or adding a registry entry — read and follow the relevant skill.**

- **`skills/orea-animated-ui/`** — how to build orea-style animated components and
  register them. Start at `skills/orea-animated-ui/SKILL.md`, then use its
  `references/` (`design-tokens.md`, `animation-patterns.md`, `registry-workflow.md`)
  and the `examples/component-template.tsx` scaffold. This skill is portable and
  works with any AGENTS.md/SKILL.md-aware agent (Claude Code, Antigravity, Codex,
  OpenCode, Cursor, Windsurf).

## Architecture

- **`components/library/`** — Each `.tsx` file is a standalone `"use client"` animated demo component. Must be registered in `registry.tsx` to appear on the gallery page.
- **`registry.tsx`** — Single source of truth for the gallery. Each entry has `{ id, title, description, Component, code }`. The `code` field is the raw source string shown to users (stored inline, not derived from file). When adding a component, add both the file and a registry entry.
- **`components/ui/`** — shadcn/ui primitives (currently `button.tsx` only, based on `@base-ui/react`).
- **`app/page.tsx`** — Gallery page that maps over `registry` and renders `ComponentCard` for each entry.
- **`app/layout.tsx`** — Root layout. Dark mode by default (`<html className="dark">`). Vercel Analytics only in production.
- **`lib/utils.ts`** — `cn()` via `clsx` + `tailwind-merge`.

## Framework & styling

- **Next.js 16** with App Router, React 19. Path alias `@/*` → `./*`.
- **Tailwind CSS v4** with PostCSS (`@tailwindcss/postcss`), `@import 'tailwindcss'` in globals.css. CSS variables in `@theme inline {}`. No `tailwind.config.*`.
- **`components.json`** — shadcn/ui config (`base-nova` style, RSC on, `lucide` icons).
- **shadcn cli** (`shadcn` package in deps) — use `npx shadcn add button` if a new ui primitive is needed.

## Quirks

- **`next.config.mjs`** disables TypeScript build errors (`ignoreBuildErrors: true`) and image optimization. Do not rely on `next build` to catch type errors — run `tsc --noEmit` separately if type-checking is needed.
- **No test framework** is configured. No CI, no pre-commit hooks, no formatter.
- **Package manager**: `npm` (has `package-lock.json`). `pnpm-lock.yaml` is stale/ignored.
- Generated by v0 — v0 artifacts (`.snowflake/`, `__v0_*.js`) are gitignored.
